# Kojouta Portfolio

Interactive portfolio — **3D Animator · Voice Actor · Blender Artist · Creator**

Built with Vue 3 + TypeScript + CSS 3D effects.

## Features

- **Typing animation** cycling roles (3D Animator → Voice Actor → Blender Artist → ...)
- **Certificates** section
- **Scroll reveal** animations
- **3D tilt cards** on projects
- **No demo embed** in project details
- Skill pills (Blender, CSS, Roblox Studio, Java, ...)
- Data-driven — edit everything in `src/data/projects.ts`

## Run locally

```bash
npm install
npm run dev
```

## Edit portfolio

Open `src/data/projects.ts` and update projects, certificates, skills, typingRoles, about.
